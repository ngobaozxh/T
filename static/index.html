Ports & Web UI

Proxy & Tunnel

Nền tảng host chỉ mở duy nhất một cổng HTTP công khai. Console này bắc cầu TCP-over-WebSocket tại /ws/tcp?port=, nên bạn có thể chạy bất kỳ SOCKS5/HTTP proxy nào bên trong container rồi dùng nó từ máy cá nhân như proxy thật.

1 — Dựng proxy trong container

Loại Port Trạng thái
Đang tải…
Proxy chỉ nghe trên loopback trong container; đưa ra máy bạn bằng bridge ở bước 2. 
zenith proxy socks5 1080
Không cần xác thực, chỉ nghe trên loopback — bảo vệ bởi token của console.
zenith proxy http 8888
Dùng cho http_proxy / https_proxy hoặc trình duyệt.
Có sẵn: microsocks, tinyproxy, privoxy, squid, proxychains4, socat, redsocks. Cài thêm gì cũng được: apt-get install -y <package>.

3 — Kiểm tra nhanh

curl -x socks5h://127.0.0.1:1080 https://ifconfig.me

Proxy đi ra ngoài (cho chính container)

Chưa cấu hình.
export http_proxy=http://user:pass@host:port
export https_proxy=$http_proxy
export all_proxy=socks5://user:pass@host:port
# hoặc dùng proxychains cho mọi chương trình
proxychains4 curl https://ifconfig.me
Sửa /etc/proxychains4.conf để cấu hình chuỗi proxy cố định.

Desktop GUI

Chạy môi trường đồ hoạ đầy đủ (XFCE) qua VNC rồi xem trực tiếp trong trình duyệt bằng noVNC — đi xuyên qua reverse proxy nên không cần mở thêm cổng nào. 

zenith desktop start
Lần đầu sẽ tự cài XFCE + TigerVNC + noVNC (vài phút). VNC ở 5901, noVNC ở 6080. 
zenith desktop stop      # dừng
zenith desktop status    # kiểm tra
zenith desktop install   # chỉ cài, không chạy
Kích thước mặc định 1440x900. Đổi: zenith desktop start 1920x1080.

Trình duyệt trong desktop

apt-get update && apt-get install -y firefox-esr
# chạy Firefox qua proxy SOCKS5 nội bộ
firefox-esr
GUI tốn RAM. Trên gói hosting free (khoảng 512 MB) XFCE có thể chậm — cân nhắc zenith desktop start --light để dùng openbox thay vì XFCE.

Không tìm thấy zenith CLI trong container — các nút cài/chạy sẽ không hoạt động.

Thông tin máy

Ghi chú giới hạn thật sự

  • Bạn có toàn quyền root bên trong container: cài gói, chạy service, mở port nội bộ tuỳ ý.
  • Reverse proxy và TCP bridge gỡ bỏ giới hạn "chỉ một cổng public" của nền tảng host.
  • Không thể làm: nạp kernel module, KVM/nested virtualization, sửa kernel host, dùng cổng public khác ngoài cổng được cấp.
  • Hệ thống file thường không bền vững sau khi deploy lại — lưu dữ liệu quan trọng ra ngoài.
